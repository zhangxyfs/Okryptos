# 图谱改版方案：中心辐射布局 + 语义边校准 + 慢速漂移

日期：2026-08-27（定稿待实施，计划 2026-08-28 做）
状态：方案定稿
前置：图谱页已上线（master c3c360e + 布局修复 8cc86bc + sem 边 d56a66b + 物理调参 a3f928a）

## 0. 用户反馈与实测诊断

真机试用三点反馈：

1. **"还是 5 大坨，完全没啥关系"** —— 布局按类目（rule/pitfall/note/reference…）分簇，
   因为 `CLUSTER=0.05` 的类目焦点环力决定分组，边不参与成簇。语义边没起效（见下）。
2. **"所有条目没做语义相似边处理"** —— 做了但没生效。真实库实测（91 条目，dim 1024）：
   top-1 余弦中位数 0.651；阈值 0.75 全库仅 ~4 条边（去重后），肉眼不可见。
   阈值 0.65 → ~41 条，0.60 → ~75 条。**结论：0.75 阈值对真实向量分布太严，需校准到 0.65 档。**
3. **"飞的太快，鼠标完全点不到"** —— 用户不要静止（明确"没说要停止永动"），
   要的是"架构总览那块那样缓慢移动"。当前 master 上的冷却冻结（a3f928a）方向过头，需回调。

## 1. 目标形态

以**架构总览 + 演进历程为视觉中心**（下称"中心双锚"），其余条目通过语义相似边
连接到与中心相关的各个节点上，形成中心辐射、语义成簇的图；节点**缓慢漂移**（可点中），
不冻结、不狂飞。

## 2. 改动方案（三部分）

### 2.1 语义边阈值：动态校准（后端，internal/gui/graph.go）

- **不做固定阈值**。0.75/0.65 这类写死的值换一个库就失准（真实库 top-1 余弦中位 0.651，
  换个向量模型或换个项目分布就变了）。
- **动态校准**：每次 `apiGraph` 出图时，先算每条目 top-3 候选的相似度分布，再反推阈值使
  去重后边数 ≈ 0.45×节点数（即平均度 ≈0.9~1，"刚好成簇不糊"的状态，用户定稿目标）。
  实现：收集全部 top-3 候选分值（≤3n 个），按目标边数取对应分位的分值作阈值。
- **护栏**：阈值钳制在 [0.55, 0.75] 区间——下限防"为了凑边数把垃圾相似度也连上"
  （低于 0.55 的边宁可不要，孤点靠边是正常形态）；上限防高分库一条边都不出。
  条目数 <10 的小库直接用下限 0.55（样本太少分位无意义）。
- 计算时机 = 每次出图（页面进入/切项目都会重拉 /api/graph），天然覆盖"条目/内容变更后"
  的校准需求，不需要单独的触发时机或缓存。n≤2000 时开销毫秒级，n>2000 走既有护栏跳过。
- 测试：固定阈值用例改写——夹具控制候选分值分布，断言边数随节点数缩放、阈值落钳制区间、
  全低分库（全 0.3）不出边、全高分库（全 0.9）阈值不超过 0.75 上限。

### 2.2 布局重构：类目焦点环 → 中心双锚（前端，web/app.js gLayoutFoci/gTick）

- **删除类目焦点环**（gLayoutFoci 的 ring 逻辑）：类目从此只决定配色，不决定位置。
- **中心双锚**：架构总览与演进历程（is_dir 两节点）初始化在中心左右 ±120px 并**强锚定**
  （pinned 语义不变，但每帧施加回中力把它们钉在中心附近）；其余节点统一受向心力
  （GRAV 不变）+ 边弹簧 + 斥力——成簇完全由边（struct/ref/sem）驱动，语义相近自然聚拢。
- **无向量的孤立条目**（无边）会被斥力甩到外围——符合"没关系就靠边"的直觉。
- CLUSTER 力删除（或保留一个极弱的 0.005 档防止纯边缘孤儿飞太远，二选一，实施时实测决定）。

### 2.3 慢速漂移（前端，回调 a3f928a 的冻结）

- **撤销冷却冻结**（gFrame 停帧分支与 pointerdown 重启回退到永动 rAF）——用户明确不要静止。
- 保留：alpha 地板 0（a3f928a 已改）、速度死区 0.02（已改）。
- **限速**：位移钳 ±12 → **±1.5**（px/帧），并把积分速度整体乘 0.5 档（实施时实测手感，
  目标：节点漂移肉眼可见但 300ms 内位移 < 10px，点击命中无压力）。
- 初始预跑 900 tick 收敛逻辑不变（预跑用原速度快速收敛，只限制展示期的每帧位移）。
- 验收判据：CDP 采样连续 300 帧，最大节点位移 ∈ (0, 1.5]px/帧；模拟 pointerdown
  命中移动中的节点成功率 100%（20 次采样）。

## 4. 风险与备注

- 语义边效果依赖真实向量质量：动态校准后"误连"（跨域高分）表现为平均度达标但边质量差，
  评审时目视抽查 10 条边的合理性；误连多则把目标平均度下调（0.9→0.7）或抬高下限钳。
- 中心双锚布局在 >400 分层模式下：骨架恒含双锚 + 高 deg hub，展开类目时成员围绕
  其语义邻居收敛——分层逻辑不用改，但焦点删除后展开初位从球心改为邻居质心（实施细节）。
- a3f928a 的冻结回退后，"接口失败停 rAF"的终审修复（b1718c4）必须保留——
  那是错误分支资源回收，与永动/冻结之争无关。
