# OkMeter 横向 Dock（顶部 / 状态栏上方）设计定论

> 来源：2026-09-13 原型迭代（`prototype/dock-horizontal-bar` 分支，
> 主文件 `docs/prototypes/prototype-dock-horizontal-v2.html`，基于
> `okmeter-dock-prototype.html` 全量动画体系）。本文只记**用户拍板的结论**，
> 实现（C++ `okmeter/`）以此为准。

## 形态与吸附

- 采纳**居中簇状条**（A 变体）：条宽 = 条目数 × 块宽，水平居中；顶部 = 从顶缘垂下，
  底部 = 贴任务栏上沿。**全宽状态条（B）与把手+抽屉（C）已否决**。
- 吸附边扩为四个：左 / 右 / 上 / 下（状态栏上方）。**左/右竖条一切既有行为
  完全不变**（收缩露半条 + 55% 降暗、弹簧滑出、wave 流向镜像、级联菜单、详情卡）
  ——横向功能必须全部挂在 `isHoriz()` 分支下，竖向逐一回归。

## 收缩样式（mini 态）

- **收缩不是截断、不沉出屏外**（两案均已被用户否决）：收缩是**另一种独立样式**——
  紧凑 chip 排，每个 chip 只有 名称 + token 读数（居中项 accent），条高 ~32px 贴缘。
- chip 与 stage 同源：读数跳动、标签切换实时同步。

## 展开 ⇄ 收缩动画（逐项 morph）

- **每个条目自己变形**，不是两层交叉渐隐（交叉渐隐看着像"向右渐隐"，已否决）：
  ① 框变换——宽/高/圆角从形态块渐变到 pill（圆角 %→px 先算实数）；
  ② 文字随框移动（不做独立文字动画）；
  ③ 波形/量条/数码等形态细节随框高塌缩渐隐。
- **展开 = 收缩的精确反向**（CSS 过渡天然对称）。不做任何独立入场动画
  （itemin 弹入会盖掉连续变形，已否决）。
- 鼠标离开 → 600ms 迟滞回缩（沿用竖条逻辑）。

## 详情卡

- **形变进行中禁弹卡**：收缩悬停立即弹卡会按展开态坐标错位、再被形变触发的
  pointerleave 关掉（乱序 bug）。形变结束（~360ms）后按指针实际落点
  （elementFromPoint 命中）补弹。
- 方向：顶部 → 向下弹；底部 → 向上弹；水平居中对齐条目并夹取视口。

## 形态切换（硬约束）

- **mini 态是形态切换的中继站**：展开态切形态 → 先 morph 缩回 chip 排 →
  落定后静默销毁重建。chip 与形态无关，画面连续。
- **销毁重建绝对禁止淡入淡出/过渡帧**（用户两次强调）：C++ 实现里重建必须
  像素级连续——同位置同内容重绘，不允许任何 opacity 动画。
- 边缘切换（左↔右）与竖向维持原样直接重建。

## 其他

- glow 材质环境光源换缘（上缘 → 光在屏顶之外；下缘 → 光在任务栏之外）。
- arc 形态弧线朝屏幕中心鼓（上缘向下弯 / 下缘向上弯）；compass 保持径向占方形区。
- 级联右键菜单、设置面板（吸附边增 上/下（状态栏上方））、拖拽换边、
  多屏位置规则均需方向适配；菜单/卡片的锚定修复（menuMainScreen_）逻辑沿用。
