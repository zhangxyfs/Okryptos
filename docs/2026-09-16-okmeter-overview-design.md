## 名称

**「用量总览」**（窗口标题 `OkMeter 用量总览`，菜单项 `用量总览…`）。

## 定位

一个**只读统计弹窗**：把 dock 上"当前时刻读数"扩展为"时间维度上的分布与节奏"——
日/周/月/年四个范围，按提供商 → 模型两级拆分 token 用量，外加一张全年跨度的
Token 活动热力图，回答"这段时间 token 都花在哪了、哪天最忙"。

与既有 UI 的分工：

- 条目读数 / 悬停详情卡 = 单点的当前值（今日/本周/本月/上月/累计）。
- **用量总览 = 时间序列的分布（主图）、构成（明细表）与长期节奏（活动图）**，
  不替代详情卡。

## 入口

右键级联菜单主列，`设置…` 上方新增叶项 `用量总览…`（action 打开弹窗）。
仅此一个入口（v1 不加 dock 按钮，条上每一像素都是读数区）。

## 窗口形态

**并集扩窗**（与设置面板同源，已验证路径）：弹窗期间 dock 保持展开
（holdOpen），窗口矩形 = dock ∪ 总览面板；总览面板**定位于工作区中央**，
尺寸 = **工作区宽 × 80%、高 × 80%**（运行时现算；设最小宽 640×最小高 480
保底，极小工作区退化为夹取可视区）。

**面板主题（v5 修订）**：面板自带**浅/深双主题**，照原型两款 UI（浅色=
prototype-overview-v2、深色=prototype-overview-v1 的 CSS 变量原样换算），
**与 dock 材质系统解耦**（不走材质供皮）；标题栏 ✕ 左侧主题切换钮（太阳/
月亮）即点即换，选择持久化 `config.overviewTheme`（"light"/"dark"，默认
light）。热力色阶按主题各一套；图表语义色（chartcolors）两主题通用。

- 独立顶层 HWND 方案已否决（v1）：需要第二套 swapchain/render target、
  独立消息循环与点击穿透管理，收益（可拖离 dock）不值这个成本；v2 再议。
- ESC 关闭；点面板外（dock 区以外）不关闭（防误触丢视图，与设置面板一致）。
- 打开期间采集照常刷新，面板数据随 poll 周期重算（与详情卡同源节奏）。

### 范围 tabs（即点即切，拍板 10：桶数固定）

视图状态全部不写盘（非设置项，不适用"勾选+保存两段式"约定），每次打开
默认「日 · 柱状 · 每日活动图」。

| 范围 | 桶数（固定） | 分桶口径 |
|------|-------------|----------|
| 日 | 7 | dayKey 当日 |
| 周 | 4 | 周一界（复用 `weekStartKey`） |
| 月 | 12 | yyyymm 月键（同 `modelMonth` 口径） |
| 年 | 全部 | dayKey/10000 |

- 无桶数选择器；顶栏只有范围 tabs + 图型钮。
- **平移/缩放（拍板 7 保留部分）**：
  - 主图横向**拖拽平移**：向过去方向拖动即按桶加载更早历史，直到数据起点
    （最早 byDay）；向未来最多拖回"最近一桶"。平移偏移是视图状态。
  - **滚轮缩放**：以指针位置为锚改变单桶像素宽（下限 = 固定桶数正好放下，
    上限 = 单桶 120px）。
  - 柱/曲线/悬停层一律裁剪进 plot 矩形（原型教训：桶位计算多算一格 +
    无裁剪 → 柱身画进 Y 轴刻度区；刻度标签只为中心在 plot 内的桶绘制，
    与柱中心共用 x 坐标天然对齐）。
  - 活动图不参与平移/缩放（它本身就是全景）。

### 范围切换动画（拍板 11：morph，柱与趋势都要）

切换范围 tab 时**形变过渡**（参考 Kimi 官网用量页手感），不是跳变：

- ~450ms，缓动 = dock 同款 cubic-bezier(.22,.8,.3,1)。
- **日期映射（柱状）**：以"键日期"（日=当日、周=当周周一、月=当月 1 日、年=元旦）
  对齐新旧两帧——共有键的位置与分段值双双插值；仅新帧有的键从基线长出
  （新周桶从"周一那天的日值"长到周合计，正是形变手感来源）；仅旧帧有的
  键沉回基线消失。Y 轴 maxV 同步插值，网格线/刻度每帧重算不瞬跳。
- **形状插值（趋势）**：每条曲线视为函数 y(x)，64 个采样点对旧/新曲线
  分别取值后逐点混合；**水平跨度（首末桶中心间距）同步插值**——跨度差异大
  的切换（日 7 桶 ≈86% 宽 → 年 2 桶 ≈50% 宽）是逐渐收缩/拉宽，禁止满宽
  外推采样（原型教训：外推采样会在动画终帧瞬跳"突然变短"）。
- 动画期间重复切 tab：以当前帧实时几何为旧态起新动画，无跳变、无鬼影。
- 动画期间禁用悬停 tooltip；拖拽/缩放/显隐/下钻等直接操作立即终止动画。
- 图型切换（柱⇄趋势）不做 morph，150ms 交叉淡入淡出。
- X 轴刻度独立分层：morph/淡化期间新旧两套刻度按 alpha 交叉过渡（实现期
  闪烁排查结论：点击→动画路径原子无直出帧，真实可感跳变来自刻度瞬切格式）。
- 活动图 tabs 不做动画。

### 主图：堆叠柱状图 ⇄ 趋势图（可切换）

顶栏右侧 `[柱状|趋势]` 分段钮切换图型。两种图型**共用同一套分桶数据、
图例过滤与下钻状态**，只是呈现不同。

**堆叠柱状图**

- **堆叠维度 = 提供商**；下钻后 = 该提供商的**模型**（见"图例"）。
- 值 = 桶内 token total（输入+输出含缓存，与全表口径一致）。
- Y 轴自适应最大值，千分位网格线。
- 柱悬停 → tooltip 卡（复用详情卡视觉）：日期桶标题 + 各分段分列 + 合计，
  一律千分位原数（沿用"有单位看着更费劲"的用户裁决）。

**趋势图（平滑曲线）**

- 每个可见分段（提供商；下钻后为模型）一条**平滑曲线**，色同图例；
  弧线观感用单调三次插值（Fritsch–Carlson），过数据点且不自激震荡；
  不用直角折线（生硬）、不用贝塞尔甩尾（超调造假象）。
- 不画"合计粗线"——总量趋势就是各线之和的视觉包络。
- 悬停任意 x → 垂直参考线 + tooltip 卡（同柱状版式），参考线吸附最近桶中心。
- 零量桶照常出点（值 0），序列连续不压缩。

### 图例（过滤 + 下钻，拍板 3）

- 默认列出当前窗口内有量的**提供商**：配色块 + 名称 + 区间合计 + `›` 下钻标。
- **点击配色块（或行首眼睛标）= 显示/隐藏**该提供商（堆叠/曲线中剔除，
  Y 轴重自适应；至少保留一项，最后一项不可关——防全空图）。
- **点击名称/`›` = 下钻**：图例切换为该提供商的模型清单，主图堆叠维度随之
  变为模型，顶栏出现面包屑 `‹ 返回提供商`；再点 `‹` 回到提供商层。
  下钻内同样支持逐模型显隐（同样保底一项）。
- 趋势图下钻后每模型一条线，交互一致。
- 显隐状态与下钻位置都是视图状态，不写盘，关窗即忘。

### 明细表

- 跟随图例层级：提供商层列 **提供商 → 模型** 两级降序表；下钻后只列该提供商
  的模型明细。组头行显示合计；每行 `短名 … 千分位 token`。
- 受显隐过滤（隐藏的分段不列）；行悬停时主图对应分段高亮（其余降暗，
  沿用详情卡"他项降暗"的既有语言）。
- **模型名归并（v5 修订，明细/图例/右键级联菜单三处同规则）**：
  大小写不敏感归并（GLM-5.3 ≡ glm-5.3），显示名取最近使用的原始大小写；
  归并后仍同短名的（跨命名空间，如 kimi-code/k3 与 claude-code/k3）加
  " · 命名空间"后缀（沿用级联菜单既有规则）；mapping 持久化值仍写最近使用
  的原始完整 modelId，存量配置兼容。

### 配色（拍板 9：数量不限、两两可辨）

- **策展色**：已知大厂给固定语义色（月之暗面/OpenAI/DeepSeek/通义/混元/
  智谱/Anthropic/Google…），映射表集中在图表模块内。
- **溢出提供商**：黄金角（≈137.5°）在 HSL 色相环上逐家步进生成
  （S≈65%、L≈55% 固定），相邻提供商色相天然大跨距；与策展色冲突时
  （ΔHue<25°）再步进一位。生成序 = 该提供商首次出现序，同一会话内稳定。
- **不随材质换肤**：材质只决定底板/描边/文字色，图表语义色跨材质一致。
- 活动图热力色阶例外：单色 accent 透明度分档（见下节），不占提供商色板。

### Token 活动图（热力日历）

GitHub 贡献图式热力格子，表达**长期节奏**（哪天有活、哪天猛），与主图的
"近窗口分布"互补。参考样式：用户提供的「Token 活动」截图。

- **粒度 tabs**：`每日 | 每周 | 累计`（视图状态，默认「每日」），**三档统一为
  7 行 × N 周列日历格阵**（v5 修订：此前"每周=1×N 横条"画错已废；v6 修订：
  星期行标 一/三/五/日，月份轴标月份首列、跨年时去年的月份照标）：
  - 每日：格 = 天着色；跨度 = **固定最近 52 周**（v6：数据不足一窗时更早的
    日子画空档格，满宽不留空白）。
    tooltip：`2026年9月15日 · 2,691,234 tokens · 40 轮消息`。
  - 每周：**整周列 7 格按该周合计统一着色**（本周列只画到今天）；悬浮列内
    **任意格子弹同一 tooltip**：`2026年9月19日 · 当周`（D日=悬停格日期）+
    该周合计 tokens/轮数（千分位原数，不用"万"单位）。
  - **累计（拍板 5）**：格 = 天，**值 = 当周累计**（周一截至当日），色阶随
    周内攀升；tooltip：`截至 2026年9月17日 · 当周累计 1,234,567 tokens · 89 轮消息`。
- **色阶**：5 档（0 / 低 / 中 / 高 / 极高），单色 accent 透明度递进
  （0 档用底板色）；阈值按当前粒度窗口内非零格分位数现算（P50/P75/P90），
  数据少自然退化，不写死绝对值。
- **月份轴**：格阵下方标月份首列（同截图样式）。
- 轮数为 0（旧数据无计数）时 tooltip 省略"轮消息"段，不显示"0 轮"凑数。
- 点击格子无行为（只读）；tooltip 即全部交互。
- **格阵右侧「累计摘要」统计卡组**（2 列 × 3 行，填充原右空档）：累计 tokens、
  累计轮数、活跃天数、日均 tokens、峰值日（日期+量）、当前连续活跃天数——
  全部从 byDay 现算，只读无点击；全跨度静态值，不随粒度 tab 联动。
  格阵宽度自适应铺满剩余左区（格子近正方形，clamp 像素范围）。

## 数据口径

- 来源：全局 `dayAll_` + 各 `ModelStat::byDay`；提供商聚合 = 按 `providerOf` 归并。
- 周/月/年由 byDay 现算（同 `modelWeek`/`modelMonth` 的口径，无新增存储）。
- 数据起点 = 最早 byDay 日期，底注如实显示；年视图按数据实际跨度出柱。
- 未观测/零量桶照常出零值（时间序列连续，不压缩）。
- **消息轮数（schema 演进，拍板 6）**：`Sums` 增加 `msgs` 字段——`add()` 每条
  事件 +1，`plus()` 累加，`total()` 语义不变（仍只算 token）。持久化写为可选
  字段，**旧 state.json 缺省读 0**（fromJson 本就容忍缺字段）；老数据 tooltip
  自动省略轮数段。采集适配器零改动。一句话：从上线那天起开始数消息条数，
  之前的日子只显示 token、不显示轮数。

## 硬性约束（沿用既有裁决）
