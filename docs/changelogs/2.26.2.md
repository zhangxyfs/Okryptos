# 2.26.2 OkMeter 横向悬浮条与提供商分组菜单

## 新功能

- **悬浮条支持吸附屏幕顶部 / 状态栏上方**：吸附边从左/右扩到四边。上/下吸附时悬浮条变为横向居中簇状条；收缩态不再是截断，而是变换为只显名称与读数的迷你条目排，展开⇄收缩为逐项渐变动画（框体形变 + 文字移动 + 细节渐隐），鼠标离开自动回缩；切换视觉形态全程无闪烁。详情卡、右键菜单、设置面板均按吸附方向自动调整弹出方位；波形流横向时恒从左往右流，"现在"恒定朝向屏幕中心。

## 改进

- **右键「模型」菜单改按真实提供商分组**：同一模型被多个 Agent 使用时归到同一提供商下（如月之暗面旗下的 k3、k3-256k），不再按工具名分散成多列；同名模型的三级项标注来源工具（如 `k3 · kimi-code`）。

## 说明

- 升级不影响已有的指标映射与吸附边配置，原左/右竖条形态的行为逐像素不变。
