# OkMeter 详情卡读数万/亿单位化

日期：2026-09-13

悬停详情卡的数值从纯千分位（`2,103,434,288`）改为**万/亿单位 + 全位数保留**的格式：单位只作小数点分隔符使用（`21.03434288 亿` / `90.6288 万`），一位不丢、不做四舍五入，整数部分完整的单位自动去尾零（`21 亿`）。数字与单位间加空格。大数字与「今日 / 本周 / 累计」行值统一走该格式。

新增 `fmtYi` 格式化函数（`okmeter/core/fmt.cpp`）：亿=右数 8 位、万=右数 4 位处插小数点并修剪尾部零。

测试：`tests/test_fmt.cpp` 新增 `fmt_yi_units` 用例（0 / 千位以下 / 万边界 / 亿边界 / 修剪尾零）；51 个 C++ 单测全绿；`--shot` 自检截图确认卡片读数 `21.03434288 亿` 排版。
