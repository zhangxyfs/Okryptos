# 2.22.0 管理页 wiki 目录化 + 稳定性与安全性修复

## 新功能

- **演进历程目录化**：与架构总览同为双身份节点（文件夹图标，点名看索引正文、展开看版本段子条目，按版本号数值升序 v2.9 < v2.10）；主条目瘦身为主题索引。老库升级零迁移可读，无版本段时详情区给出迁移提示（对 agent 说「更新 wiki」即可按新结构自动迁移，幂等可重入）。

## 改进

- **知识树交互**：类目行/双身份节点的展开改 400ms 计时双击检测（原生 dblclick 在整页重渲下永不触发）；设置页「✓已保存」反馈定向摘除不再整页重渲，打字不再丢字符；终端历史上限 200 条；批准按钮请求期间防重复点击；管理页轮询加交错保护。
- **CLI 一致性**：`ok add --force` 覆盖写继承盘上原条目的 created/draft/archived（归档/草稿不再被静默转正）；`ok init`/`ok add`/`ok propose`/备份导入补齐与 GUI 同款的项目名与标题形状校验（路径穿越/Windows 保留名/大小写冲突/空 slug）；`ok index` 未配置 embedding 时降级退出码归 0；`ok wiki mark` 不再吞索引同步错误。
- **安装器**：数据目录定位改 `%USERPROFILE%`（Documents 重定向不再指错）；卸载确认默认按钮改为「否」；装完默认勾选打开配置中心。

## 修复

- **安全加固**：API token 不再内嵌首页 HTML，改经 URL fragment 一次性注入（不发服务器、不进 Referer）；daemon 全 mux 加 Host/Origin 校验（Host 必须回环、跨源 403、永不输出 CORS 头），掐断 DNS rebinding 远程链；LLM/embedding 连通性测试回查已存 key 时绑死已存 base_url（改地址必须重填 key），ollama 模型探测限回环目标；条目「AI 优化」的正文路径引用做包含性复核，`../` 不再可读项目根外文件外发；全部 JSON 端点统一 4MB 请求体上限。
- **并发与锁**：embedding 网络调用移出索引写事务（全量重建期间 hook 注入不再静默为空数分钟）；配置行级写全部收口进文件锁（不再丢刚保存的 API key）；文件锁 stale 抢占改 rename 抢先消除竞态，注册表走严格锁；索引变化判据改 mtime+size 双判（同秒双写不再漏同步）；损坏 vectors.json 自动隔离 `.bad` 不再拖垮整个知识库。
- **hooks 自愈**：daemon 进程内自愈补 CLI 入口换算（hooks 不再被改写成指向 okd.exe，doctor 误报消除）；kimi 显式卸载不再被复活；zcode 尊重 hooks.enabled 开关；qoderide 补认原生工具名。
- **其他**：changelog_required 规则的 glob 匹配双边折叠大小写（`CHANGELOG.md` 惯例写法不再永不命中）；wiki 状态 git 子进程加 5s 超时；anthropic base_url 自动去重 `/v1`；注入与 INDEX 渲染对条目元数据消毒（伪造小节头/指令行不再可能）。

## 说明

- 无行为回退风险：检索/注入/钩子协议口径不变；存量索引库首轮全量重读一次（幂等）。
