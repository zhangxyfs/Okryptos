# 2026-09-13 OkMeter：液态玻璃胶囊项真实折射 + 边缘色散（学 liquid-glass-react）

## 问题

液态玻璃与毛玻璃在胶囊/块状形态（波形流、胶囊量表、电平柱、辉光数码）下肉眼
无区别：液态的折射链路只服务圆球（球体弧线），pill 项走 `drawFrostFallback`
——与毛玻璃同一条 11px 模糊 + 12% 白染管线，且通透度不足。

## 修复（参考 D:\develop\liquid-glass-react）

1. **pill 项折射**：位移场从单位圆推广到超椭圆（P=4，拟合圆角矩形域，对应
   参考项目的 roundedRectSDF），`h=(|nx/a|^P+|ny/b|^P)^(1/P)` 边界 h=1，中心
   58% 零位移、边缘环带沿梯度外推；位移图按项半轴比懒烘缓存（a 变化 >0.004
   才重烘）。pill 项与圆球共用同一条 位移→微模糊(σ0.75)→提饱和→提亮 链，
   环境染色同为 desk-deep 9% + 左上 15% 径向——玻璃体通透、内容仅被边缘
   "舔"一下，不再糊不再盖白。
2. **边缘色散**：R/G/B 三通道各按 1.0/0.9/0.8 比例位移、ColorMatrix 隔离后
   经 D2D Blend(screen) 混合——中心零位移区三通道采样同点，混合恒等原图，
   彩虹彩边只出现在位移环带。任一节点创建失败自动退回无色散链。

毛玻璃材质保持原样（奶白模糊），两材质在所有形态下均有明确区分。

## 测试

- `build.bat` 编译 + 51 单测通过，/W4 零警告。
- 在线 A/B（同机同背景图案窗：20px 网格 + 红/蓝文字，WM_APP+0x4C 转储 +
  排除自身截图）：液态下条目内透出网格与文字、边缘可见折射弯曲；毛玻璃下
  条目奶白不透。像素实测：条目内行 min/max (47..113) 与背景网格 (25..90)
  对比度一致，仅整体提亮（tintHl 所致），折射未压扁内容。
- 白底深底兜底（luma>0.45 触发 60% 深底）行为不变。
