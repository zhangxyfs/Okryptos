# 2.26.5 Orosus 接入与用量总览

## 新功能

- **引导页新增 Orosus 接入**：自研模块化 AI 编程助手 CLI Orosus 进入引导页，一键完成 hooks 接入——知识注入、触碰记账、规则评估三条链路自动写入 Orosus 的 hooks 配置，安装/自愈/卸载与 ZCode、Codex 等同款体验；本机装有 Orosus 时卡片自动出现。
- **OkMeter 用量总览弹窗**：趋势图与 Token 活动图按日/周/月/年查看用量；图例点击过滤、按模型下钻；多提供商配色两两可辨。

## 修复

- **多端同步空远端首推死锁**：远端仓库为空或被重建后，拉取永远失败、推送永远执行不到，本地提交无限堆积；现在自动识别该场景并降级直推，一次同步完成自愈。

## 说明

- 无知识库数据与配置格式变化。
- OkMeter 统计新增消息轮数计数，旧统计文件兼容（从 0 起计），用量口径不变。
