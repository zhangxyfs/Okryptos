# 2.26.4 升级收尾自动恢复

## 修复

- **升级后配置中心与悬浮条自动回来**：此前一键升级（静默安装）会强制关闭配置中心与 Token 监视器悬浮条，装完只拉起 daemon——配置中心和悬浮条就此消失，需要手动重开。现在安装器在关闭进程前记录哪些在运行，装完原样恢复；交互式与静默升级行为一致，且交互快速升级不会重复打开配置中心。
- **修复升级后偶发"配置中心未自动打开"**：等待 daemon 就绪的预算从 3 秒放宽到 30 秒——升级后新程序冷启动（安全软件扫描、组件初始化）常超过 3 秒，旧预算会误判"未就绪"直接退出。

## 说明

- 本次为升级体验修复小版本，无数据与配置格式变化。
- 从低版本升级到本版时，执行安装的仍是旧版安装器，恢复行为需从本版往更高版本升级时开始生效。
