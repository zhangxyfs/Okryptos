# 2.24.0 强制改密：初始密码登录必须改密 + 自助修改密码

## 新功能

- **强制修改初始密码**：root 在服务器页新建用户或重置密码后，该用户持初始密码登录时会被强制要求先设置新密码——除改密外的所有操作都被拦截并弹出改密窗口，改密成功后自动解锁。root 自己首次使用自动生成的初始密码登录同样适用。
- **自助修改密码**：所有用户登录后可随时通过顶行「修改密码」入口更改自己的密码，需输入当前密码确认。

## 说明

- 版本配对：okserver 升级到本版本后，新建或被重置密码的账号要求客户端 ≥ 2.24.0 才能完成强制改密；旧版客户端登录这类账号会收到 403 提示且无法操作，请客户端与服务端同版本齐升。反向组合（新客户端 + 旧服务端）不受影响，改密入口自动隐藏。
- 存量用户不受影响：升级前已存在且未被重置密码的账号无强制改密标记，登录行为与旧版一致，可直接覆盖升级。
- 服务端镜像随本版本发布至 Docker Hub（`z7dream/openknowledge-okserver`）与 GHCR，amd64/arm64 双架构；已有 NAS 部署在 okdeploy 管理页点「升级」即可，数据卷不受影响。
