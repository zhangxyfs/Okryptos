# 2.24.3 客户端版本升级：检查更新 + 一键升级

## 新功能

- **客户端自动检查新版本**：基于 GitHub Releases，检查结果本地缓存 6 小时；网络异常或 GitHub 不可达时静默跳过，不影响任何功能。
- **「其他」页版本卡**：显示当前版本与最新版本，点「检查更新」手动刷新；发现新版本可查看更新日志并一键升级——Windows 上自动下载安装包（支持断点续传、进度条显示）并静默覆盖安装，装完程序自动重启；Linux 上提供 deb/tar.gz 下载链接。
- **启动更新提醒**：有新版本时启动 GUI 弹出提醒，可选「立即升级 / 跳过此版本 / 知道了」；跳过后同版本不再打扰；有未处理的新版本时侧栏「其他」菜单显示红点。
- **托盘「检查更新」**：Windows 托盘菜单新增入口，点击直接打开 GUI 并直达版本卡。
- **服务端版本提示**：服务器页检测到服务端版本高于客户端时提示升级客户端，避免新旧版本错配。

## 说明

- 升级安装在后台静默完成，数据与配置不受影响；安装期间守护进程短暂停止，装完自动恢复。
- GitHub 不可达时手动检查会如实提示「检查失败，请稍后重试」，不会误报已是最新。
