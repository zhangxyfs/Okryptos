# 2.25.0 产品改名 OpenKnowledge → Okryptos

## 改进

- **产品改名 Okryptos**：仓库、安装包（`OkryptosSetup-<版本>.exe`）、安装目录（`%LOCALAPPDATA%\Programs\Okryptos`）、数据目录（`~/.okryptos`）、注入前缀（`[Okryptos]`）、托盘/窗口标题、官网与文档全面切换；命令行简写 `ok`/`okd`/`okserver`/`okdeploy`/`OkManager` 不变。
- **升级即自动迁移**：从旧版升级后首次启动自动完成——数据根 `~/.openknowledge` 整体迁移为 `~/.okryptos`（含 config 内旧路径改写，幂等）；各 AI 助手的 hooks 插件/扩展换新名（okryptos.ts 等）并清除旧件；已安装到各 agent 的 `openknowledge-*` 技能副本由新名 `ok-*` 技能替换；Windows 旧自启项一并清理。无需任何手工操作。
- **服务端镜像新名双发**：okserver 镜像改用 `z7dream/okryptos-okserver`（GHCR `ghcr.io/zhangxyfs/okryptos/okserver`），过渡期旧名同步续发；已有 NAS 部署在 okdeploy 管理页点「升级」即自动切到新镜像名，数据卷不受影响。

## 说明

- **存量兼容**：旧版安装目录、deb 包名（`openknowledge`）与 Linux 自启文件名保持不变；旧版客户端的一键升级渠道（旧仓库 release 地址）继续可用——GitHub 仓库改名后旧地址自动重定向，且新版同时信任新旧两个下载前缀。
- 本地开发仓库目录是否改名不影响任何功能。
