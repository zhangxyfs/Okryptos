# 2.23.0 个人多端同步：okserver 管理面 + 一键部署器 + GUI 同步面

## 新功能

- **个人多端同步（核心）**：知识库条目是纯 Markdown 文件，本版本起可经 git 在多设备间同步。`ok sync` / `ok sync init` 命令行 + 管理页每项目的同步按钮与四态状态点（已同步/有未同步变更/未启用/冲突待解决）双入口；okd 每分钟检查、写入后 30 秒防抖自动触发，离线或服务器不可用不影响本地任何功能。
- **同步冲突三向解决页**：自动同步撞冲突时跳「解决同步冲突」页——冲突文件列表逐条给「采用本地 / 采用远端 / 合并」三按钮，合并进三向编辑器（共同祖先/本地/远端逐块对照，逐块采纳或全文手编），全部解决后一键完成同步并推送；可随时放弃本次同步回滚到同步前状态。
- **okserver 服务端管理面（可选组件，NAS Docker 部署）**：自建轻量认证（root 首启自动生成）+ 用户/组织/仓库 provisioning + 审计流水；Gitea 退居底层 git 托管，对终端用户透明。每个项目一个私有仓，「一键建仓并绑定」自动完成建仓、remote 绑定与首次推送；登录后检测到服务器已有数据而本地为空的项目，可一次确认批量拉取绑定。
- **GUI 新增「服务器」页**：连接 → 登录 → 按角色落地的三步向导。root/admin 管理视图：状态、用户（建用户/重置密码/禁用/删除，初始密码与 git token 一次性弹窗可复制）、组织与团队仓、仓库总览、审计五张卡；成员视图：我的项目绑定 + 我的组织。
- **okdeploy 一键部署器（独立小工具）**：Windows 图形界面引导式把服务端部署到 NAS——SSH 连接、环境探测（Docker/Compose/端口占用/已有部署识别）、全新部署或接入已有 Gitea 两种形态、部署完成后进入管理页（升级/重拉镜像/查看容器日志/备份/恢复/重置 root 密码/卸载），全程实时日志可下载，中英文界面切换。Linux 下提供同功能命令行形态。

## 改进

- **管理页加载大幅提速**：项目同步状态判断由每个项目 4 次 git 子进程改为纯文件系统检查，项目多、刷新频繁时不再卡顿。
- **全局弹窗组件化**：归档/删除/弃稿/建仓/禁用用户等确认与输入统一替换为应用内弹窗（Esc 或点遮罩取消、Enter 确认、危险操作红色按钮），不再是浏览器原生对话框。
- **管理操作即时刷新**：建用户/删用户/建仓等操作后列表与审计自动重拉，无需手动刷新页面。

## 说明

- 同步与服务端为可选能力：不配置服务器时本版本与旧版行为一致，单机使用完全不受影响，可直接覆盖升级。
- 服务端镜像随本版本发布至 Docker Hub（`z7dream/openknowledge-okserver`）与 GHCR，amd64/arm64 双架构；已有 NAS 部署在 okdeploy 管理页点「升级」即可，数据卷不受影响。
- 团队共享（组织内知识晋升、团队仓内容同步）为后续版本能力，本期组织卡可先完成建组织、成员维护与团队仓预建。
