# 2.22.2 稳定性加固：并发写入收口、检索与 embedding 修复、前端体验补全

## 改进

- **语义检索大幅省内存**：万级条目库下每次注入不再全量加载条目正文，改两阶段查询（先算向量相似度、命中后再回查正文）。
- **托盘双击秒开**：双击托盘图标拉起浏览器改为异步执行，不再卡住托盘消息循环；退出时序对齐，幽灵图标场景消除。
- **终端长任务不再误杀**：管理页终端按命令类别区分超时，`wiki` 等多轮长任务不再被 10 秒一刀切。
- **embedding 复测修正**：ollama 等无密钥服务的 name-only 复测不再误报「profile 不可用」。
- **README 图片令牌**：项目 README 预览图改一次性短时票据下发，长期令牌不再进入浏览器历史与书签。
- **编辑误触保护**：编辑条目时误点侧栏/知识树会先弹确认，不再静默丢弃未保存内容。
- **设置交互统一**：Reasonix 强制模式与沉淀模式统一为勾选+保存两段式，不再点选即存。

## 修复

- **并发写入丢数据**：GUI 保存配置与 hooks 自愈并发时可能互相覆盖（丢 API key、丢第三方 hooks）——宿主 settings 与全局配置的读-改-写全部收进文件锁；文件锁抢占阈值抬高并记日志，慢磁盘/杀软扫描下不再误抢存活持有者。
- **Reasonix 压缩后注入丢失**：扩展清单补登记压缩完成事件，存量旧安装会被自愈重写；各宿主接入状态检测改为比对实际配置内容，程序迁移/改名后不再误报「已接入」。
- **embedding 建库停摆**：首次建库遇网络抖动后向量写入永久停摆的问题修复——失败自动回滚本轮已写向量，下轮干净重试。
- **CLI 一批**：`ok add --file` 传入带 front matter 的文件自动剥离并提示，不再层层嵌套；`ok approve` 不再被当前目录同名文件遮蔽；`ok list` 遇坏条目给出警告而非整体消失；同目录重复注册项目直接拒绝，不再静默写串知识库；备份导入对非法文件名跳过告警，不再中途挂起。
- **hooks 卸载与兼容**：卸载不再留下指向已删文件的死命令；Codex 信任项在第三方 hooks 挤动位置后不再永久残留；用户名含单引号时 DeepSeek Harness 插件挂载不再失效。
- **sidecar 生命周期**：内置 embedding 服务崩溃计数在重启后正确归零，不再一轮误杀；daemon 退出不再被就绪等待阻塞最长 90 秒。
- **前端**：终端历史脏数据不再导致整页白屏；下载进度条顺序稳定；RRF 分数浮窗支持键盘与触屏；开关控件同步无障碍状态。

## 说明

- 本次为稳定性加固批次，无接口变化，直接升级即可；检索/注入/钩子协议口径不变。
