# 2.26.1 OkMeter 多 Agent 采集与悬浮条打磨

## 新功能

- **OkMeter 支持九家 Agent 采集**：在 Kimi Code 之外，新增 Claude Code、Codex、Qwen Code、ZCode、WorkBuddy、Reasonix、OpenHanako、DeepSeek Harness 八个适配器——各家本地会话日志的 token 用量自动进统计，右键「模型」菜单按工具分组呈现（如 `claude-code`、`zcode`、`dsh`）；各目录均有变更监听，有新数据即时刷新。

## 改进

- **波形流形态启动即有全宽平线**：不再等历史数据攒够才出波形；流向随缘镜像——dock 在屏幕左缘时从右往左流、在右缘时从左往右流，"现在"恒定朝向屏幕中心。
- 右键菜单打开期间不再叠加悬停详情卡；设置面板的指标映射下拉改用与右键一致的多级级联菜单（总量/模型→厂商→模型），锚定修复后不再出现菜单自行左跑、被设置面板遮挡的问题。

## 说明

- 各家 Agent 的 token 口径已做归一（缓存读/缓存写单独拆分）；OpenCode 因用量存在 sqlite 中暂不支持。
- DeepSeek Harness 的会话日志为压缩格式，统计走其会话投影缓存，模型名按默认配置近似。
