# 2.26.0 中文名「归藏」、检索注入精度、本地 LLM 与 OkMeter 悬浮条

## 新功能

- **中文名「归藏」**：GUI 顶栏品牌区与浏览器标题随中英切换显示「归藏 / Okryptos」，官网与双语 README 补命名词源与定位语「面向 AI-Agent Hooks 的隐性知识库」。
- **OkMeter token 悬浮条（Windows）**：桌面边缘常驻的 token 用量监视条——收缩态贴屏缘、悬停滑出；总量（当前会话/今日/本周/累计）与按模型两种口径，右键级联菜单即点即切；悬停详情卡（今日/本周/本月/累计 + 输入输出拆分）；球体弧线/胶囊量表/星环罗盘/电平柱/波形流/辉光数码六种形态 × 标准深色/毛玻璃/液态玻璃/沉浸光感四种材质，液态玻璃带真实背景折射；背板式设置面板（改完点「保存并生效」统一应用）；配置中心「token 统计工具」开关默认开启，托盘菜单可手动拉起。
- **LLM 本地推理两档**：ollama 档免 API key 直连本机 ollama；内置托管档在 GUI 一键下载模型（qwen3 1.7B 首选 / 0.6B 最省 / 4B 非思考最稳，带进度条），下载后全自动本地推理，识别意图过滤零调用费。
- **检索相关性 LLM 后置过滤**：注入前把候选条目交 LLM 裁决，只删不加；未配置、超时或解析失败一律保留原结果，不影响既有检索。
- **识别意图双「使用中」槽位**：LLM 配置新增「识别意图」专用槽，过滤调用与通用调用可分别指定模型（如过滤走本地小模型、生成走远程大模型）。

## 改进

- **关键词通道覆盖度准入**：短口语查询（如"还是黑底的"）不再因命中虚词而误注入无关条目——命中词元数须达比例门槛，纯虚词查询跳过关键词通道。
- GUI 模型配置弹窗：内置档显示模型体积与资源估算、识别意图说明分行排版、双槽徽标两行展示。

## 说明

- OkMeter 悬浮条仅 Windows 版提供，随安装包分发（绿色版可用但无单实例守护）。
- 内置托管模型需本地下载（640MB~2.5GB），运行时内存占用约 1~4GB，介意资源请选 ollama 档或远程 API 档。
