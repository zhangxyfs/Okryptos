# OkMeter 悬停反馈重构与亮背景可读性

日期：2026-09-13

**悬停反馈**按用户裁决重构：一切缩放移除（悬停项与他项尺寸一律不动），悬停反馈 = 其余项降不透明度（球体 0.6 / 块状形态 0.55）；块状项（胶囊 / 电平柱 / 波形流 / 辉光数码）悬停不再绘制 accent 描边（原型 hot 语义只保留球体弧线）；同时修掉三处环状伪影——块状项的悬停外发光椭圆与中心光晕环限制为仅圆项绘制（原型 `.orb.hot/.orb.center` 专属），以及 `cornerR` 批量接入时落入 `drawShape` 的 `grow` 参数位导致描边外扩 12px 成环的参数错位。

**亮背景可读性**系统性修复：背景亮度采样从全屏 8×8 网格改为 **dock 窗口正后方区域**（全屏均值在半屏白半屏暗时被稀释，自适应永不触发，为主因）；luma 语义从"背景亮度"改为各材质**玻璃有效亮度**（dark 材质 74% 深底恒浅墨，frost 提亮≈背景，liquid/glow≈背景）；墨色判定加迟滞（>0.62 切深墨 / <0.48 切浅墨 / 中间保持，消除明暗切换时的来回闪烁）；亮底下描边统一加深（0.16~0.26 → 0.30~0.34）；详情卡文本恒浅色（卡底四材质均为深色玻璃，修 inkOn 误用导致的亮底深字叠深底）；长模型名省略号截断。几何尺寸同步完成比例法改造（`uiScale = 屏高/1080`，几何/字体/卡片全链路，钳 0.7~1.6，多分辨率等比）。

测试：51 个 C++ 单测全绿（含 `geom_uiscale_ratio`、`geom_capsule_scales_with_screen` 比例断言）；各形态 `--shot` / 在线转储截图逐项对照原型确认。
