# 2.24.2 git 凭证统一 + 同步自愈 + 空壳项目目录关联

## 新功能

- **git 凭证统一为「每台机器一条」**：服务器上的 git 访问凭证不再随建账号、建仓库散落多条，统一为每台机器一条（按机器名命名），凭证列表就是你的机器列表。升级后本机会在下次同步时自动换新凭证，无需任何操作。
- **凭证页「清理旧版凭证」**：存在旧命名凭证时凭证卡会出现清理按钮——点击后先确保本机持有新凭证，确认框逐条列出将删除的旧凭证并说明影响，确认后批量清理。不再使用的机器，删掉对应一条即可。
- **空壳项目关联/解除工作目录**：从服务器拉取或备份恢复产生的「未关联目录」项目，现在可以直接在管理页行内点「关联目录」补挂（支持批量），挂错了也可以在「目录」弹窗里解除关联重来；命令行侧 `ok init` 对同名空壳项目也会幂等补挂当前目录。

## 改进

- **同步认证失败自动自愈**：服务器端凭证被删或失效后，同步不再永久报认证失败——客户端会自动重新申请凭证、刷新本机存储并重试一次。
- **Linux 安装后内置模型可下载**：修复 .deb 安装目录（/usr/lib，root 所有）导致模型下载必报权限错误的问题，模型目录不可写时自动回退到数据目录。

## 修复

- 修复旧版 okd 注册的 hooks 块无法被识别清理、导致同一事件重复注入的问题。

## 说明

- **版本配对**：本版本起服务端建仓/建账号不再下发 git 凭证，客户端需 ≥ 2.24.1（建议两端同升本版本）；过旧客户端在新服务端上首次绑定会提示升级，已绑定的机器不受影响。
- 服务端镜像随本版本发布至 Docker Hub（`z7dream/openknowledge-okserver`）与 GHCR，amd64/arm64 双架构；已有 NAS 部署在 okdeploy 管理页点「升级」即可，数据卷不受影响。
