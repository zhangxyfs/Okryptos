# 写入后 30s 防抖触发同步

日期：2026-08-28

GUI 条目写入（新建、编辑保存、approve 草稿转正、归档/恢复、删除）成功后，okd 以 30s 防抖触发一轮个人层同步：连续多次写入合并为一轮，未同步窗口压到分钟级以内（设计文档 §8）。同步走 `gui.Handler.OnWrite` 回调注入（gui 包不反向依赖 daemon），失败仅记 daemon 日志，绝不影响本地写入链路；未启用同步的项目不受影响。

同时修复同步引擎两处评审遗留：okd 同步周期（runSyncCycle）加互斥锁串行化——ticker 与写入防抖两条触发链路并发跑同步时，sync-status.json 的读-改-写不再存在 lost-update 窗口，同仓 git 操作也不会锁争用；注册表加载与项目配置加载失败从完全静默改为各记一行日志（`sync: ...`），同步为什么没跑从此可查。
