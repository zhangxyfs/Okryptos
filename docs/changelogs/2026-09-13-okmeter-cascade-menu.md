# OkMeter 右键三级级联菜单 + 映射悬空引用修复

日期：2026-09-13

右键菜单从单层平铺重构为三级级联：一级为「总量 ▸ / 模型 ▸ / 设置 / 换边 / 退出」（移除「默认·按最近使用」项）；「总量」二级展开四口径（当前会话 / 今日用量 / 本周用量 / 全部累计）；「模型」二级按 modelId 首段自动聚合厂商分组（kimi-code / zhipuai-coding-plan / deepseek 等，按最近使用排序，未来接入其他 agent 工具时新厂商组自动出现）；厂商三级列出该厂商下已观测到的具体模型。交互为 Windows 菜单同款：悬停父项即展开子列，子列向屏内侧逐级展开并参与窗口并集扩窗，Escape / 点外全部收起。菜单底层 `GlassMenu` 重构为多列模型（主列 + 两个 MenuColumn），命中按列号×1000+下标编码分发。

修复同期发现的「模型切换静默无效」根因：叶项的映射值是从菜单子列 `entries` 向量里**引用**出来的，应用映射前 `closeMenu()` 会 `clear()` 该向量使引用悬空，守卫读到空值静默早退。改为**按值传参**（`applyMenuMapping(std::string v)`），并在注释中记录此坑。取证链：按下/命中/分发全通而守卫读 `v.empty()==1` 一条定案。

测试：51 个 C++ 单测全绿；`--shotmenu` 自检扩展支持展开二/三级落盘截图，三张自检截图确认三列布局、屏内侧级联定位、当前映射 ✓；端到端消息注入验证点击后 mapping 落盘生效。

相关文件：`okmeter/ui/menu.{h,cpp}`（多列重构）、`okmeter/ui/app.cpp`（级联构建/悬停展开/按值修复）。
