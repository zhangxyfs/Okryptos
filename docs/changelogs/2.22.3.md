# 2.22.3 强制检查链路修复：规则口径对齐与全局合并；管理页树交互修复

## 修复

- **GUI 配置的强制检查规则全部静默失效**：设置页规则卡以 `changelog` 短写法落盘，而 Stop hook 只评估 `changelog_required`，两边口径不一致导致 GUI 配置的规则从未生效。现统一为 `changelog_required`（GUI 校验、前端下拉与默认值），旧 GUI 写入的 `changelog` 短写法在 hook 侧作别名兼容，存量配置无需手改。
- **项目级规则顶掉全局规则**：`[[enforce]]` 按 toml 数组整体替换语义合并，项目 config.toml 里只要存在任意规则（含注释示例被启用），GUI 写入的全局规则即被整体覆盖，"全局生效"落空。现改为全局与项目追加合并（全局在前），GUI 配置与手改项目文件同时生效。
- **配置合并串扰**：toml 解码数组复用原切片底层数组（含 `[]string` 字段内层数组），合并时先引用后拷贝拿到的是被覆盖的新值——曾致 enforce 合并出现"全局规则的提示语配项目规则的 globs"；embedding profiles 合并同类隐患一并修复（解码前深拷贝）。
- **管理页树交互不再连坐右侧预览**：点击目录行高亮、展开/收起目录（类目、架构总览/演进历程双身份节点、项目箭头）只重画左侧树区，不再整页重建——此前先点开项目 README 后再点任意目录，右侧预览会整段重渲染、README 图片重新加载，肉眼可见闪烁。选中条目、点项目名看 README 的行为不变。

## 改进

- **规则卡可用性**："添加规则"预填经典模板（`changelog_required` + `**/*.go` + `docs/changelogs/**` + 标准提示语），三个字段加占位示例，表格下方补判定逻辑说明行——不再对着空输入框猜语义。
- **测试安装包机制**：`scripts/build.py --test` 一键出测试包，版本号自动追加 `_test`（exe 内部版本与安装包文件名一致），不再手改 iss 文件再还原；临时脚本编完即删。
- **Wiki 知识图谱技术栈定栈验证（开发资产，未进产品功能）**：新增 `web/vendor/sigma-graph.min.js`（177KB 单文件 IIFE：sigma@3.0.3 + graphology@0.26.0 + graphology-layout-forceatlas2@0.10.1，另含自写菱形目录节点 program、屏幕空间虚线引用边 program、迭代式 ForceAtlas2 布局模拟器，复现命令见 `web/vendor/README.md`）；`docs/prototypes/` 下新增 Sigma 版图谱原型与 2.4k 节点压力版（86 节点真实数据，类目成簇布局 + 入场/拖拽回弹动效 + 搜索/图例/详情面板齐全）。实测 2.4k 节点布局收敛 ~3s、均帧 13.8ms 可撑 60fps，为后续图谱 GUI 正式开发定栈 Sigma.js + graphology。
- **GUI 新增「图谱」栏目**：左侧导航「管理」下方新增图谱页，按项目查看知识条目关系图——顶栏项目下拉切换（默认最近更新项目），条目按类目着色聚簇，力导向布局支持悬停邻居高亮、拖拽/缩放/平移、图例淡化与搜索过滤；单击节点滑出详情面板，面板内关联条目双击直跳管理页并展开树定位到该条目行。条目超 400 自动进入分层模式：首屏只渲染骨架（目录 + 高连接度条目），图例点击展开/收起类目（物理只跑可见集），搜索命中未展开叶子自动展开其类目。数据走新增的 `GET /api/graph?project=`（nodes/edges/categories 一次返回：ref 正文链接边 + wiki 目录 struct 挂载边，deg 后端算好，走 withAuth 鉴权与既有 project 参数校验）。图谱布局改版：中心双锚辐射布局（类目焦点环改配色专用）+ 语义边动态阈值（平均度≈1 分位反推）+ 慢速漂移（节点持续缓慢移动，点击/悬停命中不受影响）。密度与取景优化：力系稀疏化（弹簧原长/向心/碰撞调参）+ 收敛后自动重取景（二次 fitView 平滑放大至约 45% 屏宽，用户拖过视图则不打扰）。

## 说明

- 无接口变化，直接升级即可。配置解析失败（如手改写坏 toml）维持 fail-open：规则不生效、不阻断会话，错误记 `ok.log`；单条规则的坏 glob、未知 type 同样记日志跳过。
