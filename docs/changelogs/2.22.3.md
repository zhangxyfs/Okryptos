# 2.22.3 修复：管理页点击目录连坐刷新右侧预览

## 修复

- **管理页树交互不再连坐右侧预览**：点击目录行高亮、展开/收起目录（类目、架构总览/演进历程双身份节点、项目箭头）只重画左侧树区，不再整页重建——此前先点开项目 README 后再点任意目录，右侧预览会整段重渲染、README 图片重新加载，肉眼可见闪烁。选中条目、点项目名看 README 的行为不变。

## 改进

- **GUI 新增「图谱」栏目**：左侧导航「管理」下方新增图谱页，按项目查看知识条目关系图——顶栏项目下拉切换（默认最近更新项目），条目按类目着色聚簇，力导向布局支持悬停邻居高亮、拖拽/缩放/平移、图例淡化与搜索过滤；单击节点滑出详情面板，面板内关联条目双击直跳管理页并展开树定位到该条目行。条目超 400 自动进入分层模式：首屏只渲染骨架（目录 + 高连接度条目），图例点击展开/收起类目（物理只跑可见集），搜索命中未展开叶子自动展开其类目。数据走新增的 `GET /api/graph?project=`（nodes/edges/categories 一次返回：ref 正文链接边 + wiki 目录 struct 挂载边，deg 后端算好，走 withAuth 鉴权与既有 project 参数校验）。图谱布局改版：中心双锚辐射布局（类目焦点环改配色专用）+ 语义边动态阈值（平均度≈1 分位反推）+ 慢速漂移（节点持续缓慢移动，点击/悬停命中不受影响）。密度与取景优化：力系稀疏化（弹簧原长/向心/碰撞调参）+ 收敛后自动重取景（二次 fitView 平滑放大至约 45% 屏宽，用户拖过视图则不打扰）。

## 说明

- 无接口变化，直接升级即可。
