# 2.24.1 服务器仓拉取到本机 + 同步状态点实时化 + 凭证管理

## 新功能

- **服务器仓一键拉回本机**：换新机器或重装后，登录服务器即可在服务器页看到「可拉取」分组——服务器上有而本机未注册的项目仓一目了然，支持单个拉取或「全部拉取」，拉取完成即出现在管理页、条目齐全。登录时若发现本机缺仓会自动弹窗提示，确认后一键补齐。
- **同步状态点实时化**：项目列表的同步状态点升级为五态——灰（未配置服务器）、绿（已同步）、黄（本地有改动待同步）、黄闪（正在同步）、红（有冲突待处理）。改动落盘几秒即变黄，同步完成回绿，不用再等手动刷新。
- **凭证管理**：服务器页新增凭证卡片——成员可查看/删除自己账号在服务器上的 git 访问凭证（每台拉取过的机器一份，互不影响），管理员可查看/清理任意用户的凭证；删除用户时其凭证由服务端自动级联清理。
- **git 凭证按机器分名**：多台机器各自拉取/重发凭证互不顶掉，换机、重装不再把别的机器踢下线。

## 修复

- 修复断连服务器后凭证列表残留上一台服务器数据的问题。

## 说明

- 版本配对：拉取与凭证管理功能要求客户端与服务端同为 2.24.1；新客户端连旧服务端会提示升级 okserver，旧客户端连新服务端不受影响。
- 服务端镜像随本版本发布至 Docker Hub（`z7dream/openknowledge-okserver`）与 GHCR，amd64/arm64 双架构；已有 NAS 部署在 okdeploy 管理页点「升级」即可，数据卷不受影响。
