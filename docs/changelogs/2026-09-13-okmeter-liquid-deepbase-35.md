# 2026-09-13 OkMeter：液态玻璃亮底深底 60% → 35%（A/B 实测折中）

## 背景

用户提问：浅色背景下把之前加的黑半透明底去掉会不会更好。做三档 A/B
（同机同白底文字窗，排除自身截图对比）：

- **0%（去掉）**：条目白玻璃撞白底，数字靠光晕勉强可辨但明显费力，波形
  几乎看不见——光晕救不回白字撞白底，不可行。
- **60%（原值）**：可读性最好但条目成黑瓦片，折射/通透全被盖住，液态玻璃
  在白底下失去材质意义。
- **35%**：灰玻璃态，背景内容隐约可透，数字带光晕清晰可读——玻璃感与
  可读性的折中，采用此值。

## 改动

`liquid.cpp` 亮底兜底深底 alpha 0.60 → 0.35（仅液态玻璃；frost/glow/dark
的 60% 深底未动，需要统一再议）。
