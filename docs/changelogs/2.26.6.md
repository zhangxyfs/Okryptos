# 2.26.6 Orosus 接入修复

## 修复

- **修复引导页接入 Orosus 时写坏配置**：一键接入写入的 hooks 配置块末行与结束标记粘连成一行（形如 `timeout = 20# <<< …`），Orosus 解析该配置失败、钩子功能整体不生效；现在每行独立换行，写入即可用。
- **Orosus 触碰记账改挂正确事件**：文件写/改的记账钩子从工具执行前挪到执行后——事前跑会把「未遂的写」（工具可能被审批拒绝或执行失败）也记进台账，且执行后才能读到工具结果。

## 说明

- 仅影响 Orosus 接入路径，其余 agent 接入与既有功能无变化；无数据与配置格式变化。
- 已装上一版并接入 Orosus 的用户无需手动处理：升级后下一次提问即自动修正配置（钩子自愈），或到引导页重装一次立即生效。
